4. Pipeline 控制（新架构）

所有端点位于 /api/projects/{project_id}/pipeline/...。REST 提交命令，SSE 事件流推送状态。

Pipeline 步骤顺序：

步骤名中文名依赖上游产出
story故事大纲—stories 表
characters角色提取storycharacters 表
portraits角色肖像characterscharacter_portraits 表 + 图片文件
scene_scripts分场剧本storyscripts + scenes 表
storyboard分镜设计scene_scripts, charactersstoryboards + shots + cameras 表
shot_frames镜头帧生成storyboard, portraitsshots.image_url + 图片文件 + 视频文件
composite_video视频合成shot_framesscenes.composited_video + final.mp4
GET /api/projects/{project_id}/pipeline/events

SSE（Server-Sent Events）事件流。通过 EventSource 连接实时接收 pipeline 进度推送。返回 text/event-stream。

// 前端连接示例
const es = new EventSource("http://localhost:8765/api/projects/1/pipeline/events")
es.onmessage = (e) => {
  const event = JSON.parse(e.data)
  console.log(event.type, event)
}
es.onerror = () => {
  es.close()
  setTimeout(() => reconnect(), 3000)
}

完整事件协议见 SSE 事件协议文档。

POST /api/projects/{project_id}/pipeline/start

启动 Pipeline。支持指定 start_step 从某一步开始。

Request Body:

字段类型必填说明
start_stepstring | null可选从指定步骤开始，如 "shot_frames"，null 从头开始
chat_api_keystring可选LLM API Key，空则复用项目已有配置
chat_base_urlstring可选LLM Base URL
image_api_keystring可选图像模型 API Key
image_base_urlstring可选图像模型 Base URL
video_api_keystring可选视频模型 API Key
video_base_urlstring可选视频模型 Base URL
chat_rate_limit_mininteger可选LLM 每分钟请求上限，默认 50
chat_rate_limit_dayinteger可选LLM 每日请求上限，默认 2000
image_rate_limit_mininteger可选图像每分钟上限，默认 10
image_rate_limit_dayinteger可选图像每日上限，默认 500
video_rate_limit_mininteger可选视频每分钟上限，默认 50
video_rate_limit_dayinteger可选视频每日上限，默认 1000

Response: {"status": "started"}

错误码: 404 — 项目不存在，409 — Pipeline 已在运行

POST /api/projects/{project_id}/pipeline/pause

暂停 Pipeline（当前步骤完成后停下，不会暴力中断）。

Response: {"status": "paused"}

POST /api/projects/{project_id}/pipeline/resume

恢复被暂停的 Pipeline。如果 Pipeline 本身已完成或失败也会自动重启。

Response: {"status": "resumed"}

POST /api/projects/{project_id}/pipeline/cancel

取消 Pipeline 执行。任务被标记取消后无法恢复。

Response: {"status": "cancelled"}

POST /api/projects/{project_id}/pipeline/regenerate-step

定点重做某一步。将该步及其所有下游步骤标记为 pending，然后从该步启动 Pipeline。

Request Body:

字段类型必填说明
stepstring必填步骤名，必须是 STEP_NAMES 中之一

Response: {"status": "regenerating", "step": "shot_frames"}

错误码: 400 — 无效步骤名，404 — 项目不存在，409 — Pipeline 正在运行

6. 全局错误码

状态码说明常见原因
200成功请求正常处理
400请求参数错误缺少必填字段、无效步骤名、无数据可合成
404资源不存在项目 ID、场景 ID 不存在
409冲突Pipeline 已在运行，无法重复启动
500服务端错误AI 调用失败、数据库异常等，error 字段含详情
